
# RAINBOW RICOCHET 

A game for JS13k 2026 by [Nicklas Löf](https://mastodon.social/@snukey)

JS13k 2026 Theme: Unicorns and Rainbows.

The whole game is written in ES6 Javascript.

I made the graphics in Libresprite and compressed them with TinyPNG and Compress-or-die.

Wall and floor graphic created by https://isadu.itch.io

The sound effects was created in the exellent ZzFX web application and using ZzFX library to play them.

Minification done with rollup, google closure compiler and terser.

Black magic compression done with Roadroller.

And finally additional zip compression done with ect and advzip.


I have no build system, just using a simple compile shellscript.

Mostly no AI was harmed during the production of this game.

The game is © Nicklas Löf 2026 and can't be distributed anywhere else than at JS13kgames website https://js13kgames.com.
